\# Dockerized Employee Management System using DevOps



\## Project Overview



Dockerized Employee Management System is a full-stack web application developed to manage employee records efficiently. The project includes a Spring Boot backend, a frontend user interface, REST APIs, MySQL database connectivity, and Docker containerization.



This project demonstrates basic DevOps concepts by containerizing the backend application using Docker and running it as a Docker container.



\---



\## Features



\- Add new employee details

\- View all employee records

\- Update existing employee details

\- Delete employee records

\- REST API integration

\- Frontend and backend connectivity

\- MySQL database support

\- Dockerized backend application

\- Simple and user-friendly UI
